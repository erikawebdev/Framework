Color

Each color is a base you enter by hand, with lighter steps (l-1 up) and darker steps (d-1 up), plus its own hover. Add or remove a step on any color independently. Click a swatch to copy its variable. The outlined swatch is the base.

Transparency

Ten to ninety percent of each base color, mixed with transparent.

Classes generated

No utility classes right now. Every color, step, hover, and transparency is still available as a variable via var(), e.g. background: var(--primary) or color: var(--primary-d-2).

Typography

Same method as your type scale calculator: pick a min and max viewport, a base size at each end for the anchor step (h4 for headings, text-m for text), and a ratio. Every other step is the anchor times the ratio to a power, then clamped between its mobile and desktop value.

Headings

h4 is the anchor. h3–h1 scale up, h5–h6 scale down. Pixel values shown are at the current window width.

Heading style

Set the default for every heading on the All tab. Switch to a level to override just that level; leave a field blank to keep it inheriting the default. Text color and font size can be any value you type, including a reference to another variable, e.g. var(--primary).

Spacing

Same method as Typography: a base value at M (mobile px to desktop px) and a scale ratio, split mobile/desktop, generate XS to XXL. Section spacing takes that same scale and multiplies it, fluidly, using a separate mobile and desktop multiplier. Uses the same viewport range set on the Typography page.

Base spacing

M is the anchor. Used for padding, margin, and gap alike — spacing is just spacing.

Section spacing

The base scale above, multiplied. "M" section spacing applies to every <section> by default.

Gutter

The section's inline edge spacing, independent of the scale above.

--gutter

Contextual gaps

Container gap (between containers in a section), content gap (between content elements), and grid gap (between grid items) — each just points at one of the sizes above.

Automatic spacing

Applied sitewide with zero specificity: every <section> gets container gap, every div gets content gap. Any class or ID you add still overrides it. Turning a toggle off sets its variable to 0 instead of removing the rule, so nothing needs to be edited to turn it back on.

Auto grid gap will appear here once grid utility classes are built.

Smart spacing

Only applies inside an element with the .smart-spacing class (or a selector listed under Target Additional Selectors below) — best for content you don't fully control the markup of, like a WYSIWYG editor or an imported blog post. Use .smart-spacing--off to cancel it locally.

Heading spacing

All (H2-H6) sets the default; override a specific level below it. H1 isn't included, same as ACSS.

Advanced targeting

Target Additional Selectors: extra selectors (comma-separated, quoted) also treated as smart-spacing containers, for markup you can't add the .smart-spacing class to. Avoid Duplicate Margins: elements matching this selector get both top and bottom margin, so whatever follows one has its top margin zeroed to prevent double spacing. These two affect the downloaded CSS; they aren't demoed live above since the demo box only has default markup to show.

Layout

Grid templates to use with grid-template-columns, and the content width the auto-fit grids size against.

Grid templates

Equal columns (--grid-1 to --grid-12), ratio columns (--grid-1-2 is one part, then two parts), and auto-fit grids. --grid-auto-4 shows up to 4 columns and drops to fewer once a column would get narrower than a quarter of the content width times the aggressiveness, so lower aggressiveness keeps more columns on smaller screens. Click a name to copy it.

Breakpoints

Max-width breakpoints in px. CSS can't use variables in a media query, so these are written straight into the media queries of the downloaded file, and changing one doesn't change this page.

Radius

A base value at M (mobile px to desktop px) and one scale ratio generate XS to XL: each step down divides by the ratio, each step up multiplies by it. Uses the same viewport range set on the Typography page.

Radius scale

M is the anchor. --radius-full makes pills and circles. Pixel values shown are at the current window width; click a name to copy it.

Contextual radius

--radius is the general default. It just points at one of the sizes above.

Focus

The outline keyboard users see on whatever has focus: links, buttons, form fields, anything focusable. It only appears for keyboard focus (:focus-visible), not mouse clicks. Each button swaps in its own focus color from the Buttons page.

Buttons

One class per color, never the status colors. Check a color to give it a button style (.btn--{color}, plus light, dark, and outline); uncheck it to remove that button entirely. Every button shares one set of global settings below, matching ACSS's own button variables.

Global settings

Shared by every button color. Change one, every button follows.

Colors, per variant

Each of the 6 variants (solid, dark, light, and their outline versions) has its own background, text color, border color and focus color. Background, text color and border color each have a hover state too — click the small icon next to a field's name to switch it to editing that field's hover value.

Sizes

Links

Default styling for every <a> on the site, plus a .link--{color} class for every active color (status colors included, matching ACSS). A class on the link itself or on a wrapping parent both work, since these are just custom properties and they inherit down.
